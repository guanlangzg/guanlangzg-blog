# 观澜志博客与导航

观澜志是基于 Next.js 的文章与导航网站。本项目保留现有运行时数据格式，并从公开仓库中的 `content/seeds/` 提供初始文章和导航示例。

## 本地开发

需要 Node.js 24 和 npm 11.6.2。

```bash
npm ci
npm run dev
```

运行时文章、导航和站点设置默认保存在 `./data`，也可以通过 `BLOG_DATA_ROOT` 指定其他目录。请勿将真实运行时数据或本地凭据加入版本控制。

## 检查

```bash
npm run check
npm run build
```

生产 Compose 部署需要显式设置 `DEPLOY_IMAGE`、认证配置及持久化数据目录；当前部署骨架不设置可直接拉取的镜像默认值。生产认证、备份和发布配置须按首版开发文档完成验收后再启用。

R2 备份以明文 JSON 写入对象存储。启用前请确认 bucket 的访问策略符合数据保密要求。
