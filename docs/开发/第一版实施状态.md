## 3. 尚未完成或未验证（不得当作已通过）

1. **VPS 预览路由分流**：固定 release 文件服务与会话校验已实现，且本地路由/鉴权测试通过；VPS 对真实浏览器请求的 HTML、RSC/prefetch、HEAD、导航、媒体和 Next 资源 rewrite 行为尚未在生产样式服务环境验证。
2. **Docker / 最终 runner**：本机没有 Docker CLI；镜像、最终 runner 内的公开静态构建、权限、资源与重启恢复均未验证。
3. **真实 GitHub App**：注册、安装、仓库私有性与权限、installation token 实测未做；自动化测试使用 fake transport。
4. **真实 Pages 部署**：尚未对真实仓库提交产物或复跑工作流；Pages 站点 URL 与 GitHub Pages API 对账只用隔离测试验证。
5. **VPS 部署**：公网 5678 登录、更新、失败回滚及既有数据保留尚未在实际服务器执行。
6. **内地网络可达性**：未在真实内地网络测量页面、图片、字体和静态索引加载。
7. **`npx vitest run` 全量测试**：默认 worker pool 下 **113/115 文件、897/899 项通过**，另报告 5 个 fork worker 启动超时；两个业务失败（markdown-runtime 一个测试超时、startup-tasks 一个 handler mock 未调用）单独复跑 **17/17 通过**。尝试限制 worker 的全量命令时，当前 Vitest CLI 不认识 `--minWorkers` 参数，未实际启动；因此全量 suite 仍记为未通过/未确认，而 S3/S4 聚焦套件 **13 文件、123 项通过**。

## 4. 已知且已确认接受的风险

- 后台通过公网 **HTTP 5678** 访问：登录口令、会话与页面录入的 GitHub 凭据可能在传输途中被截获。当前确认接受该风险，不要求 SSH 隧道或 HTTPS；强口令与限流不等于传输加密。
- 公开 Git 历史与外部缓存可能保留撤回前的内容，不承诺可追溯抹除。
